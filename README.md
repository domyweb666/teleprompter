# 踏板提詞器

iPhone 用的網頁提詞器。可以用藍牙踏板或翻頁遙控器控制，也能依照你念的聲音自動跟上進度。

## 使用方式

1. 用 iPhone 的 Safari 打開網址，按「分享 → 加入主畫面」。
2. 貼上講稿，空一行代表新的一段。
3. 調整設定，上方的預覽會即時顯示實際效果。
4. 按「開始提詞」。

## 控制

| | 聲音跟隨：開 | 聲音跟隨：關 |
|---|---|---|
| 逐段跳 | 聲音推進度；▼ 跳到下一段開頭，▲ 回到這段開頭 | ▼▲ 換段 |
| 連續捲動 | 聲音推進度；▼▲ 一次挪一行，按住連續挪 | 自動捲動；▼ 加速，▲ 減速或倒退 |

| 按鍵 | 作用 |
|---|---|
| ↓ → PageDown | 往下 |
| ↑ ← PageUp | 往上 |
| 空白鍵、Enter、`.` | 暫停或繼續跟隨／自動捲動 |
| A | 逐段跳 |
| B | 連續捲動 |
| M | 逐段跳、連續捲動互換 |
| C | 聲音跟隨開／關 |
| 連按兩次 Esc | 離開提詞畫面 |

設定裡另有「左右鏡像」與「上下翻轉」，可單獨或一起開，搭配提詞玻璃或倒放的螢幕使用。

## 注意

- 聲音跟隨需要允許麥克風。如果沒有反應，請到 iPhone「設定 → Siri」確認聽寫功能有打開。
- 講稿和設定只存在這支手機的瀏覽器裡，不會上傳。
- 錄影和提詞最好用不同的裝置，否則麥克風可能會被搶走。
